# MINDRACE / MIYA ARENA — পুনরায় tiklangan loyiha

## Ishga tushirish
`index.html` faylini brauzerda oching yoki barcha fayllarni GitHub repozitoriyingizga yuklang va Vercel'da deploy qiling.

## Fayllar
- `index.html` — responsive interfeys, fan/mode tanlash, jamoa sozlamalari, mashina tanlash.
- `js/app.js` — navbatlar, taymer, ball, natija ekrani, 3 raundli Arena turniri, audio ohanglar, klaviatura boshqaruvi, til almashtirish.
- `js/questions.js` — bir nechta fanlar uchun mahalliy savollar banki.
- `assets/utc-logo.svg` — vaqtinchalik/oddiy logo.
- `PROJECT_NOTES.md` — talablar va cheklovlar.

## O‘yin rejimlari
- 120 metr poyga
- Diqqat dueli
- Soatga qarshi
- Arena turniri (3 raund)

## Muhim cheklovlar
Bu qayta tiklangan mustaqil frontend. U asl ChatGPT Sites loyihasining eksporti emas. Savollar banki kengaytirilgan, ammo bu har bir darslikdagi barcha savollar yoki asl saytdagi to‘liq bazaning aynan o‘zi degani emas. Musobaqa hozir bitta qurilmada navbat bilan o‘ynaladi; internet orqali real vaqt multiplayer, serverda hisob/reyting saqlash, admin paneli va autentifikatsiya mavjud emas. Ruscha va inglizcha UI tarjimasi qisman; savollarning asosiy qismi o‘zbekcha. Musiqa Web Audio orqali yaratiladigan sodda ohang, original audio emas.

## Claude uchun
Barcha fayllarni birgalikda yuklab, mavjud funksiyalarni saqlagan holda savollar bankini, tillarni, animatsiyali avtomobil poygasini va kerak bo‘lsa backendni kengaytiring.
